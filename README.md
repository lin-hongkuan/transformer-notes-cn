# Transformer 完全图解

中文、图文并茂的 Transformer 学习讲义，包含交互演示，可离线打开 `site/index.html`。

## 发布

在线阅读：[Transformer 完全图解](https://lin-hongkuan.github.io/transformer-notes-cn/)。GitHub Actions 会在推送到 `main` 后将 `site/` 发布至 GitHub Pages。

源文档按章节保存在 Codex 工作区的 `work/transformer-notes-src/`；运行 `build.ps1` 生成交付页，再将生成的 `index.html` 复制到 `site/index.html`。
